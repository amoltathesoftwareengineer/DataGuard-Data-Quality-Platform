
# DataGuard — Data Quality & Pipeline Monitoring Platform

## Overview

DataGuard is a data engineering project designed to identify data quality issues and monitor data processing pipelines.

It focuses on detecting missing values, duplicate records, invalid data, and unusual changes in datasets.

## Key Features

- Data quality validation
- Duplicate record detection
- Missing value identification
- SQL-based data profiling
- Pipeline execution monitoring
- Data quality reporting
- Interactive dashboard (planned)

## Technology Stack

- SQL
- Python
- PostgreSQL
- Pandas
- Streamlit

## Use Cases

- E-commerce data validation
- Customer data quality checks
- Sales reporting data validation
- ETL pipeline monitoring
- Database quality assessment
